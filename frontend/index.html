Fundamentos del Modelo Lotka-Volterra

El sistema diferencial de Lotka-Volterra modela la interacción ecológica entre dos poblaciones biológicas: presas ($x$) y depredadores ($y$):

$$\frac{dx}{dt} = \alpha x - \beta x y$$
$$\frac{dy}{dt} = \delta x y - \gamma y$$

Parámetros de Presa:

  • $\alpha$: Tasa intrínseca de natalidad exponencial sin depredadores.
  • $\beta$: Tasa de depredación o probabilidad de encuentro fatal.

Parámetros de Depredador:

  • $\delta$: Eficiencia biológica para convertir biomasa de presa en crías.
  • $\gamma$: Tasa de mortalidad natural por senescencia o escasez.

Puntos de Equilibrio y Constante de Movimiento:

El sistema presenta un punto de equilibrio no trivial dado por: $(x^*, y^*) = (\gamma / \delta, \alpha / \beta)$.

Además, existe una cantidad invariante conservada $V(x, y)$ a lo largo de cualquier solución:

$$V(x, y) = \delta x - \gamma \ln(x) + \beta y - \alpha \ln(y) = \text{Constante}$$

Método Numérico Runge-Kutta 4º Orden (RK4)

Tanto el backend en Java como el motor autónomo en JavaScript implementan el algoritmo clásico de 4 evaluaciones ponderadas por paso temporal: $$y_{n+1} = y_n + \frac{\Delta t}{6} (k_1 + 2k_2 + 2k_3 + k_4)$$ Garantizando un error de truncamiento local de orden $\mathcal{O}(\Delta t^5)$ y global $\mathcal{O}(\Delta t^4)$.
